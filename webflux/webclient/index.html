    WebClient¶

    WebClient is the non-blocking, streaming HTTP client (Reactor Netty underneath). In Boot, inject the auto-configured WebClient.Builder (from spring-boot-webclient) — it carries codecs, observation/tracing and customizers — and build one client per downstream service.

    @Configuration
class ClientsConfig {
    @Bean
    WebClient inventoryWebClient(WebClient.Builder builder) {
        return builder.clone()                         // don't mutate the shared builder
                .baseUrl("http://inventory:8080")
                .defaultHeader(HttpHeaders.ACCEPT, MediaType.APPLICATION_JSON_VALUE)
                .build();
    }

    @Bean
    InventoryClient inventoryClient(WebClient inventoryWebClient) {
        return new InventoryClient(inventoryWebClient);
    }
}

    A production-shaped call¶

    /** A resilient downstream call with WebClient: status mapping, timeout, retry, fallback. */
public class InventoryClient {

    public record Stock(String productId, int available) {
    }

    public static class InventoryUnavailableException extends RuntimeException {
        public InventoryUnavailableException(String message) {
            super(message);
        }
    }

    private final WebClient webClient;

    public InventoryClient(WebClient webClient) {     // built from the auto-configured WebClient.Builder
        this.webClient = webClient;
    }

    public Mono<Stock> stock(String productId) {
        return webClient.get()
                .uri("/inventory/{id}", productId)
                .retrieve()
                .onStatus(status -> status.value() == 404, resp -> Mono.empty())   // 404 → empty Mono
                .onStatus(HttpStatusCode::is4xxClientError, resp -> resp.createException())
                .bodyToMono(Stock.class)
                .timeout(Duration.ofSeconds(2))                                    // per attempt
                .retryWhen(Retry.backoff(3, Duration.ofMillis(100))
                        .filter(InventoryClient::isTransient)
                        .onRetryExhaustedThrow((spec, signal) -> signal.failure())) // surface the real cause
                .onErrorMap(InventoryClient::isTransient,
                        e -> new InventoryUnavailableException("inventory down: " + e.getMessage()));
    }

    private static boolean isTransient(Throwable e) {
        return e instanceof WebClientResponseException w && w.getStatusCode().is5xxServerError()
                || e instanceof java.util.concurrent.TimeoutException;
    }
}

    retrieve() vs exchangeToMono()¶

    retrieve() exchangeToMono(resp -> ...)
    Error statuses become WebClientResponseException (customise with onStatus) you inspect resp.statusCode() yourself
    Body handling bodyToMono, bodyToFlux, toEntity, toBodilessEntity you must consume or release the body
    Use 95% of calls status-dependent decoding

    Flux<PriceTick> ticks = webClient.get().uri("/products/{id}/prices", id)
        .accept(MediaType.TEXT_EVENT_STREAM)
        .retrieve()
        .bodyToFlux(PriceTick.class);          // elements arrive as the server emits them

    Timeouts at every layer¶

    HttpClient http = HttpClient.create(ConnectionProvider.builder("inventory")
                .maxConnections(200)
                .pendingAcquireTimeout(Duration.ofSeconds(5))
                .maxIdleTime(Duration.ofSeconds(30))
                .build())
        .option(ChannelOption.CONNECT_TIMEOUT_MILLIS, 2_000)       // TCP connect
        .responseTimeout(Duration.ofSeconds(3));                   // first response byte
WebClient client = builder.clientConnector(new ReactorClientHttpConnector(http)).build();
// …and the operator-level .timeout(...) for the whole Mono, including decoding and retries.

    Filters (ExchangeFilterFunction)¶

    ExchangeFilterFunction logRequest = ExchangeFilterFunction.ofRequestProcessor(req -> {
    log.info("{} {}", req.method(), req.url());
    return Mono.just(req);
});
WebClient client = builder.filter(logRequest).build();

    Common filters: auth header injection / OAuth2 token relay (see OAuth2), correlation-id propagation, metrics.

    Testing without a server¶

    Stub the transport with an ExchangeFunction:

    // Stub the transport with an ExchangeFunction: no server, no mock-server library needed
AtomicInteger calls = new AtomicInteger();
ExchangeFunction flakyThenOk = request -> Mono.just(calls.incrementAndGet() < 3
        ? ClientResponse.create(HttpStatus.SERVICE_UNAVAILABLE).build()
        : ClientResponse.create(HttpStatus.OK)
                .header(HttpHeaders.CONTENT_TYPE, MediaType.APPLICATION_JSON_VALUE)
                .body("{\"productId\":\"p1\",\"available\":7}")
                .build());
var inventory = new InventoryClient(WebClient.builder().exchangeFunction(flakyThenOk).build());

StepVerifier.create(inventory.stock("p1"))
        .expectNext(new Stock("p1", 7))
        .verifyComplete();
assertThat(calls).hasValue(3);   // two 503s retried, third call succeeded

    For full HTTP fidelity use OkHttp's MockWebServer or WireMock.

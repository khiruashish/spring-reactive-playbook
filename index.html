    Spring Reactive Playbook¶

    Reactive programming with Project Reactor, Spring WebFlux and Spring Boot 4, from the Reactive Streams spec to a production food-delivery microservice. Every example is real, tested code.

    A complete, hands-on guide to reactive programming with Spring — from the Reactive Streams specification to production microservices — built on Java 21+ and Spring Boot 4.1.2 (Spring Framework 7, Project Reactor 3.8, Reactor Netty 1.3).

    Every example is real code

    The Reactor and WebFlux examples in this playbook are not pasted text: they live in the playbook-examples module as 97 passing JUnit tests and are embedded into these pages at build time. If an example breaks, the docs build breaks.

    How this playbook is organised¶

    flowchart LR R([Roadmap: pick your level]) --> A A[Fundamentals] --> B[Project Reactor] B --> C[Spring WebFlux] C --> D[Reactive Data] C --> E[Security] C --> F[Messaging] D & E & F --> G[Resilience & Observability] G --> H[Testing] H --> I[Production] I --> Q[Interview Questions] Q --> J[[Food Delivery App]]

    The Roadmap tab maps every page to an experience level (0–2, 2–5, 5–8, 8–12, 12–15+ years) and the Interview tab tests each level. Every topic tab uses small, generic examples (numbers, users, products, price tickers) so each concept is seen in isolation. The final Food Delivery App tab composes all of them into one event-driven system you can run with Docker Compose.

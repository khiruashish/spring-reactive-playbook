    2. WebClient Fan-Out with Partial Fallbacks¶

    L2 ★★☆ · Mono.zip, per-call timeout, onErrorResume, required vs optional

    Problem¶

    A profile page needs the user (required), recent orders and loyalty points (optional). Call the three services in parallel. A slow or failing optional service gives a fallback and a "degraded" note, while a failing required call fails the whole response. Test it without a network.

    Key idea¶

    Mono.zip subscribes to all its sources at once, so latency is that of the slowest call. Each optional call gets its own timeout and onErrorResume, which turn failure into a value. Here that value is a small Result carrying the fallback and the reason, so zip never sees an error from it. The test plugs a stub ExchangeFunction into the real WebClient, which keeps the actual encoding and decoding but needs no server.

    sequenceDiagram participant A as aggregator participant U as /users participant O as /orders (5 s) participant L as /loyalty (503) par zip subscribes to all A->>U: GET A->>O: GET (timeout 200 ms) A->>L: GET end U-->>A: user L-->>A: 503 → fallback 0, "loyalty: 503" Note over A,O: 200 ms → fallback [], "orders: timeout" A-->>A: Profile(user, [], 0, degraded)

    Solution¶

    P02ProfileAggregator.java
    package com.example.reactive.playbook.codinginterview;

import java.time.Duration;
import java.util.List;
import org.springframework.web.reactive.function.client.WebClient;
import org.springframework.web.reactive.function.client.WebClientResponseException;
import reactor.core.publisher.Mono;

/** Problem 2: fan out to 3 services with WebClient in parallel; required vs optional calls; timeouts + fallbacks. */
public class P02ProfileAggregator {

    public record User(String id, String name) { }
    public record Order(String id, long cents) { }
    public record Profile(User user, List<Order> recentOrders, int loyaltyPoints, List<String> degraded) { }

    private final WebClient http;
    private final Duration optionalTimeout;

    public P02ProfileAggregator(WebClient http, Duration optionalTimeout) { this.http = http; this.optionalTimeout = optionalTimeout; }

    public Mono<Profile> profile(String userId) {
        Mono<User> user = http.get().uri("/users/{id}", userId).retrieve().bodyToMono(User.class);   // required: errors propagate

        Mono<Result<List<Order>>> orders = http.get().uri("/orders?user={id}", userId).retrieve()
                .bodyToFlux(Order.class).take(3).collectList()
                .timeout(optionalTimeout)
                .map(Result::ok)
                .onErrorResume(e -> Mono.just(Result.fallback(List.of(), "orders: " + reason(e))));

        Mono<Result<Integer>> points = http.get().uri("/loyalty/{id}", userId).retrieve().bodyToMono(Integer.class)
                .timeout(optionalTimeout)
                .map(Result::ok)
                .onErrorResume(e -> Mono.just(Result.fallback(0, "loyalty: " + reason(e))));

        // zip subscribes to all three at once: latency = slowest call, not the sum
        return Mono.zip(user, orders, points).map(t -> new Profile(t.getT1(), t.getT2().value(), t.getT3().value(),
                java.util.stream.Stream.of(t.getT2().degraded(), t.getT3().degraded()).filter(java.util.Objects::nonNull).toList()));
    }

    private static String reason(Throwable e) {
        if (e instanceof java.util.concurrent.TimeoutException) return "timeout";
        if (e instanceof WebClientResponseException w) return String.valueOf(w.getStatusCode().value());
        return e.getClass().getSimpleName();
    }

    record Result<T>(T value, String degraded) {
        static <T> Result<T> ok(T v) { return new Result<>(v, null); }
        static <T> Result<T> fallback(T v, String why) { return new Result<>(v, why); }
    }
}
    P02ProfileAggregatorTest.java
    package com.example.reactive.playbook.codinginterview;

import static org.assertj.core.api.Assertions.assertThat;

import java.time.Duration;
import java.util.List;
import java.util.Map;
import java.util.function.Function;
import org.junit.jupiter.api.Test;
import org.springframework.http.HttpStatus;
import org.springframework.web.reactive.function.client.ClientResponse;
import org.springframework.web.reactive.function.client.WebClient;
import org.springframework.web.reactive.function.client.WebClientResponseException;
import reactor.core.publisher.Mono;
import reactor.test.StepVerifier;

/** WebClient with a stubbed ExchangeFunction: real request/response/decoding, no network, no mock server. */
class P02ProfileAggregatorTest {

    static WebClient stub(Map<String, Function<String, Mono<ClientResponse>>> routes) {
        return WebClient.builder().exchangeFunction(req -> {
            String path = req.url().getPath();
            return routes.entrySet().stream().filter(e -> path.startsWith(e.getKey())).findFirst()
                    .map(e -> e.getValue().apply(path)).orElse(Mono.just(ClientResponse.create(HttpStatus.NOT_FOUND).build()));
        }).build();
    }

    static Mono<ClientResponse> json(String body, long delayMs) {
        return Mono.delay(Duration.ofMillis(delayMs)).map(x -> ClientResponse.create(HttpStatus.OK).header("Content-Type", "application/json").body(body).build());
    }

    @Test
    void allHealthy_returnsFullProfile_inParallel() {
        var agg = new P02ProfileAggregator(stub(Map.of(
                "/users", p -> json("{\"id\":\"u1\",\"name\":\"Ana\"}", 100),
                "/orders", p -> json("[{\"id\":\"o1\",\"cents\":500},{\"id\":\"o2\",\"cents\":700}]", 100),
                "/loyalty", p -> json("120", 100))), Duration.ofSeconds(1));
        long start = System.nanoTime();
        StepVerifier.create(agg.profile("u1"))
                .assertNext(p -> {
                    assertThat(p.user().name()).isEqualTo("Ana");
                    assertThat(p.recentOrders()).hasSize(2);
                    assertThat(p.loyaltyPoints()).isEqualTo(120);
                    assertThat(p.degraded()).isEmpty();
                }).verifyComplete();
        assertThat(Duration.ofNanos(System.nanoTime() - start)).isLessThan(Duration.ofMillis(290));   // ~100 ms, not 300
    }

    @Test
    void slowAndFailingOptionalServices_degradeGracefully() {
        var agg = new P02ProfileAggregator(stub(Map.of(
                "/users", p -> json("{\"id\":\"u1\",\"name\":\"Ana\"}", 10),
                "/orders", p -> json("[]", 5_000),
                "/loyalty", p -> Mono.just(ClientResponse.create(HttpStatus.SERVICE_UNAVAILABLE).build()))), Duration.ofMillis(200));
        StepVerifier.create(agg.profile("u1"))
                .assertNext(p -> {
                    assertThat(p.recentOrders()).isEmpty();
                    assertThat(p.loyaltyPoints()).isZero();
                    assertThat(p.degraded()).containsExactly("orders: timeout", "loyalty: 503");
                }).verifyComplete();
    }

    @Test
    void requiredServiceFailure_failsTheWholeProfile() {
        var agg = new P02ProfileAggregator(stub(Map.of(
                "/orders", p -> json("[]", 10), "/loyalty", p -> json("1", 10))), Duration.ofSeconds(1));   // /users -> 404
        StepVerifier.create(agg.profile("nobody")).expectError(WebClientResponseException.NotFound.class).verify();
    }
}

    Walkthrough¶

    Code Why
    Mono.zip(user, orders, points) Parallel by construction. The first test asserts that three 100 ms calls finish in well under 300 ms.
    .timeout(optionalTimeout).map(Result::ok).onErrorResume(e -> Mono.just(Result.fallback(...))) The order matters: the timeout must sit before onErrorResume, so the timeout error is what gets converted into the fallback.
    bodyToFlux(Order.class).take(3).collectList() take(3) cancels the upstream after three items, so a long list isn't downloaded.
    WebClient.builder().exchangeFunction(req -> ...) A test seam built into WebClient. Responses are created with ClientResponse.create(status).body(json).
    expectError(WebClientResponseException.NotFound.class) The required call has no fallback, so retrieve() turns the 404 into an exception that fails the zip.

    Complexity¶

    Approach Time Space
    latency max(call latencies, bounded by timeouts) O(response sizes)

    Run it¶

    ./gradlew :playbook-examples:test --tests '*P02ProfileAggregatorTest'

    P02ProfileAggregatorTest: 3 tests, 0 failures
  ✔ all healthy · returns full profile · in parallel
  ✔ required service failure · fails the whole profile
  ✔ slow and failing optional services · degrade gracefully

    Common mistakes¶

    • Using flatMap chains (user.flatMap(u -> orders...)), which makes the calls sequential: latency is the sum.
    • onErrorResume before timeout, so the timeout fires after the fallback point and fails the zip.
    • Letting an optional source complete empty. zip then completes empty and the whole profile disappears. Always map to a value.

    Follow-up questions¶

    zip vs zipWhen vs Mono.when?

    zip combines independent sources in parallel. zipWhen runs the second source after the first, with the first's value (dependent calls). when waits for completion and ignores values, which suits fire-and-forget side effects.

    How do you add retries and circuit breaking?

    Add retryWhen(Retry.backoff(2, 100ms).filter(transient)) per call, inside the timeout budget, and Resilience4j's transformDeferred(CircuitBreakerOperator.of(cb)), or Spring Cloud Circuit Breaker's ReactiveCircuitBreaker. Problem 12 builds one by hand.
